\chapter{The consolidated recognition matrices}

\begin{orient}
\textbf{What this chapter is for.} Every chapter of this book ends with a recognition matrix scoped to its own material. This chapter collects the highest-value rows into five cross-domain tables, one per part, so that a reader with a problem in front of them and no idea which chapter it belongs to has a single place to look. The tables are deliberately terse. Each row is a surface feature, the move it should trigger, and the fallback if that move fails; the chapter that owns the move is where the reasoning lives. Read the leftmost column only, until something matches.
\end{orient}
