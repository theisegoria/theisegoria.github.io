Practice

Questions are generated fresh at three levels, so you can keep practising.

Composition and associativity

If $f(x) = 2x$ and $g(x) = x + 3$, what is $(g \circ f)(4)$?

$g(f(4)) = g(8) = 11$. Composition applies the right-hand function first.

Functors

A functor sends identities to identities and composites to composites. Does $F(i) = 2i$ from the chain $0 \le 1 \le 2$ to the chain $0 \le \dots \le 4$ respect order?

Yes: if $i \le j$ then $2i \le 2j$, so every arrow goes to an arrow, and composites are preserved because there is at most one arrow between objects.

Universal properties

In the category of sets, how many arrows are there from a 3-element set into a one-point set?

Exactly one: every element must go to the single point. This is the universal property of the terminal object.
