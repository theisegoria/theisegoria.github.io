# Isegoria

The source for [isegoria.io](https://isegoria.io), an independent publication shelf for field guides and essays.

## Structure

- `index.html` — publication home
- `library/` — the complete publication archive
- `essays/` — the essay archive
- `publications/` — permanent publication pages
- `downloads/` — stable downloadable editions
- `assets/` — shared styles and publication artwork

The site is deliberately static: it requires no build step and can be served directly by GitHub Pages.
