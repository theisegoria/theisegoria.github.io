Integrated Medical Foundations

I am building an English–Japanese study resource from MCAT foundations through pre-clinical medicine. The expanded draft now has 105 chapters and 246 corresponding TTS modules per language, alongside an earlier 95-chapter concise edition. Markdown is the canonical text, and each module is meant to be met four ways: read, heard as narration, drilled as cards, and seen as a mindmap. Complete expanded EPUBs preserve that text and pass EPUBCheck; Kobo rendering and Kindle conversion still need testing.

Anki study cards: early draft

810 matched learning objectives, which is that many English cards and that many Japanese cards, across 44 TTS modules. Coverage remains partial; 202 of the 246 inventoried modules have no cards yet. Native APKG packages are built alongside the TSV imports, from the same source, for the whole deck and for each module. Structural checks pass and the exporter carries its own test suite; actual Anki import and independent editorial review remain pending.

The exporter that produced the releases before 2026-09-15 was not preserved in this repository, and the module fingerprints it recorded match no contiguous slice of either manuscript under any normalisation I tried. I have rebuilt the exporter with a documented slicing recipe and restamped every fingerprint from the published masters. Treat the earlier fingerprints as unverifiable rather than as evidence.

Module mindmaps

Each mindmap is one TTS module compressed to its structure, so the same material can be revised as a shape rather than as prose. The canonical form is a constrained Markdown outline in which heading depth is node depth, and one build script derives the rest: a PDF to print, a PNG to look at, an OPML file that opens in MindNode, XMind, iThoughts or Freeplane, and the SVG behind them. Colour carries branch membership, one hue per branch from a colour-blind-safe palette, with depth carried by fill and weight instead. 30 modules are drawn so far, in both languages.

Expanded edition preview

The 2026-09-14 chemistry checkpoint adds Chapter 105 in both languages: amount and concentration, density, limiting reactants and yield, then acid–base equilibria, buffers and titration. Earlier physiology, pathology, anatomy and clinical material is retained. Original worked examples have numerical regression checks and 44 paired retrieval objectives. These remain study drafts, not clinical guidance or a finished curriculum.

The current complete manuscripts contain 105 chapters and 246 paired explicit narration modules. The new English modules contain 1,293 and 1,344 words, approximately 9–10 minutes at the assumed planning pace. Japanese narration needs voice calibration; timing and independent translation review are not finished across the books. Full corresponding EPUBs include all current text, with 106 content documents each including front matter. Text preservation, navigation and EPUBCheck 5.3.0 pass with zero errors or warnings. Actual Kobo rendering and Kindle conversion remain untested.
