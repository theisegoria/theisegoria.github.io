## Status rules

Each row needs separate evidence for English lesson, Japanese lesson, paired recall objectives, original application practice, scientific/editorial review, translation review, narration timing, import/update testing, and live release. File existence proves only a draft. Card totals prove neither conceptual depth nor exam readiness. Japanese resources are learning aids; retain English technical terms where useful for exam transfer.

The identifiers below are planning IDs, not new textbook chapter IDs. Bind each to existing canonical chapter/module IDs after inspecting the actual text; allocate new modules only where necessary. Preserve existing note IDs and scheduling compatibility.

2. Link the eight paired quantitative cards to specific lesson objectives and practice questions. Source fingerprints alone are not claim-level evidence.
3. Resolve module 101-1 narration length separately from supplemental exercises; do not insert answer keys into the narration by accident.
4. Audit existing baseline chapters before drafting chemistry prerequisites, then expand a matched lesson/card/practice batch.
5. Build downloadable Anki packages and test first import, reimport without duplicate notes, changed-answer updates and preservation of review scheduling in a disposable profile.
6. Publish bounded releases with live checksum verification. Record the exact commit and which editorial checks remain pending.

## Completion boundary

Expand these groups into atomic objectives with exact official reference locations before claiming comprehensive coverage. GAMSAT reasoning and writing need performance practice in addition to background knowledge. A completed deck cannot establish essay quality or unseen-passage performance. Every release should state which rows changed, not a percentage inferred from total cards.
