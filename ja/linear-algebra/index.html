線形代数：変換の幾何

座標・面積・固有ベクトル・射影・特異値を実験します。

前提知識: ベクトルと初等代数

1. 基底と座標2. 行列式、体積、階数3. 固有ベクトルと反復4. 射影としての最小二乗法5. 特異値と階数

予想してから操作し、各実験の練習問題で理解を確かめてください。練習問題は三つの難易度で毎回新しく生成されます。グラフは数式の図示であり、証明ではありません。

1. 基底と座標

円形のハンドルをドラッグするか、スライダーで基底を変えてください。強調したベクトル (1,1) は動きませんが、新しい基底での座標は変わります。行列の列は標準基底の像です。

計算例. B=diag(2,1) なら (1,1) の座標は (1/2,1) です。

注意点. 列が一次従属なら基底ではなく、逆行列は存在しません。

2つの列が一致するとどうなりますか？

平面が直線に潰れます。解が存在しても座標は一意に定まりません。

参考文献: MIT OpenCourseWare · Linear Algebra

2. 行列式、体積、階数

A の列は基底ベクトルの像なので、A は単位立方体を Ae₁, Ae₂, Ae₃ の張る平行六面体に移し、その符号付き体積が det A です。ここでは最初の二つの列が床の上にあるので、底面は 2 × 2 の区画が作る平行四辺形で面積は |ad|、体積はその底面積に高さ k を掛けた det A = adk になります。上のベクトルを横に動かす（p と q）のはせん断で、体積は変わりません。行列式が負なら向きが反転し、因子が一つでも 0 なら立体は潰れて階数が下がります。再生を押すと、立方体が像へと変わる様子が見えます。

計算例. diag(−2, 1, 1) は体積を 2 倍にし、向きを反転させます。a = d = k = 1、c = 0.7、p = 0.4、q = 0.3 では立方体はせん断されますが、体積は 1 のままです。

注意点. 行列式が1でも、長さや角度を保つとは限りません。

せん断は面積を変えずに形を変えられますか？

はい。行が (1,s)、(0,1) の行列は、どの s でも行列式が1です。

参考文献: MIT OpenCourseWare · Linear Algebra

3. 固有ベクトルと反復

固有基底を回転させ、2つの固有値を変えます。反復で各固有ベクトル成分が別々に伸縮します。破線は不変な方向です。

計算例. 固有値が1.2と0.5なら、一方の成分は増大し、他方は減衰します。

注意点. この実験は実対称行列に限定しています。実数の回転行列に実固有ベクトルがあるとは限りません。

両方の固有値の絶対値が1未満なら、軌道はどこへ向かいますか？

両方の固有値の累乗が0に近づくため、原点へ向かいます。

参考文献: MIT OpenCourseWare · Linear Algebra

4. 射影としての最小二乗法

直線 y = x₀ + x₁t を t = 0, 1, 2 の三つのデータ点に当てはめます。一般に三点すべてを通る直線はないので、Ax = b には解がありません。データのベクトル b は、Ax の全体である平面、つまり A の列空間の外にあります。最小二乗法はその平面上で b に最も近い点 p = Ax̂ を選び、これが直交射影です。残差 e = b − p は平面に垂直で、その三つの成分がデータの図での縦のずれです。データ点をドラッグするか、3D 表示で b をドラッグしてください。

計算例. b = (0.6, 2.4, 1.8) のとき Aᵀb = (4.8, 6) で、AᵀA = [[3, 3], [3, 5]] から x̂ = (1, 0.6) です。よって p = (1, 1.6, 2.2)、e = (−0.4, 0.8, −0.4) で、e は両方の列 (1, 1, 1) と (0, 1, 2) に垂直です。

注意点. 最小二乗法が最小化するのは縦のずれの二乗和です。点との垂直距離が最小の直線ではなく、外れ値が一つあるだけで大きく引っ張られます。

残差が 0 になるのはいつですか？

b がはじめから列空間にあるとき、つまり三点が一直線上にあるときです。(1, −2, 1) は両方の列に垂直なので、条件は b₁ − 2b₂ + b₃ = 0 です。

参考文献: MIT OpenCourseWare · Linear Algebra

5. 特異値と階数

入力を回転し、直交する2方向に伸縮させ、出力を回転します。単位円の像は楕円です。小さい方の伸縮を除くと階数1の近似になります。

計算例. diag(2,0.5) の最良の階数1近似は diag(2,0) で、作用素ノルムの誤差は0.5です。

注意点. 特異値は非負ですが、一般には A の固有値とは異なります。

第2特異値が0だとどうなりますか？

楕円は線分に潰れ、階数は1になります。

参考文献: MIT OpenCourseWare · Linear Algebra
