練習問題

問題は3つのレベルで毎回新しく作られるので、何度でも練習できます。

合成と結合法則

$f(x) = 2x$、$g(x) = x + 3$ のとき、$(g \circ f)(4)$ はいくつですか。

$g(f(4)) = g(8) = 11$ です。合成では右側の関数を先に適用します。

関手

関手は恒等射を恒等射に、合成を合成に写します。鎖 $0 \le 1 \le 2$ から鎖 $0 \le \dots \le 4$ への $F(i) = 2i$ は順序を保ちますか。

はい。$i \le j$ なら $2i \le 2j$ なので、すべての射が射に写ります。対象の間の射は高々1本なので、合成も保たれます。

普遍性

集合の圏で、3元集合から1点集合への射は何本ありますか。

ちょうど1本です。どの元も唯一の点に写る必要があります。これが終対象の普遍性です。
