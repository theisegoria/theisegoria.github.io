数学オリンピックの問題

B, C を通り内接円に接する円

三角形 \(ABC\) の内接円 \(\omega\) は辺 \(AB\) と点 \(F\) で接し，頂点 \(A\) に対する傍心を \(J\) とする。\(2\) 点 \(B,C\) を通り \(\omega\) に接する円を \(\Gamma\) とし，その接点を \(T\) とする。このとき，\(4\) 点 \(B,F,T,J\) は同一円周上にあることを証明せよ。

解答を開く

記号. 内心を \(I\)，内接円の半径を \(r\) とし，\(\omega\) が \(BC,\ CA\) に接する点をそれぞれ \(D,\ E\) とする。直線 \(\ell,m\) のなす有向角を \(180^\circ\) を法として \(\measuredangle(\ell,m)\) と書く。これにより以下の議論は三角形の形によらない。

\(T\) を直接扱わない理由. 接するという条件は使いにくい。よく知られた帰結は「\(TD\) が \(\angle BTC\) を二等分する」ことであるが，これだけでは \(J\) や \(F\) について何も分からない。そこで扱いやすい点 \(T'\) を先に作り，それが求める性質をすべてもつこと，\(B,C,T'\) を通る円が \(\omega\) に接すること，さらに \(B,C\) を通り \(\omega\) に接する円がただ一つであることを示す。すると \(T=T'\) となる。

段階 1：二組の平行線. \(BD=BF\) であるから，角の二等分線 \(BI\) は線分 \(DF\) の垂直二等分線であり，\(DF\perp BI\) である。外角の二等分線 \(BJ\) も \(BI\) に垂直であるから，\(BJ\parallel DF\) を得る。同様に \(CJ\parallel DE\) である。

段階 2：仮の点. \(J\notin BC\) より直線 \(DJ\) は \(BC\) と異なり，\(BC\) は \(D\) における \(\omega\) の接線であるから，\(DJ\) は \(\omega\) と \(D\) 以外の点 \(T'\) で交わる。\(J\) は \(BC\) に関して \(\omega\) と反対側にあるから \(T'\ne J\) である。また \(T'=F\) とすると \(J\) は直線 \(DF\) 上にあることになるが，\(DF\) は \(BJ\) と平行で \(B\) を通らないから，これは起こらない。同様に \(T'\ne E\) である。\(\omega\) 上の円周角，\(F\) における接弦角（そこでの接線は \(AB\)），段階 1 を順に用いると

\[\measuredangle(T'J,T'F)=\measuredangle(T'D,T'F)=\measuredangle(ED,EF)=\measuredangle(FD,AB)=\measuredangle(BJ,BF)\]

を得る。よって \(B,F,T',J\) は同一円周上にある。\(C\) の側でも \(CJ\parallel DE\) と \(E\) における接線 \(AC\) を用いて同じ計算を行えば，\(C,E,T',J\) も同一円周上にあることが分かる。

段階 3：\(T'J\) は \(\angle BT'C\) を二等分する. \(\omega\) と \(BC\) の共有点は \(D\) のみであるから \(T'\) は \(BC\) 上になく，\(B,C,T'\) を通る円 \(\Gamma'\) が定まる。段階 2 の二つの円から \(\measuredangle(T'B,T'J)=\measuredangle(FB,FJ)\)，\(\measuredangle(T'J,T'C)=\measuredangle(EJ,EC)\) である。直線 \(AI\) に関する鏡映は \(J\) を固定し，\(AF=AE\) より \(F\) と \(E\) を入れ替え，直線 \(AB\) と \(AC\) を入れ替える。鏡映は有向角の符号を反転するから \(\measuredangle(EC,EJ)=-\measuredangle(FB,FJ)\)，すなわち \(\measuredangle(FB,FJ)=\measuredangle(EJ,EC)\) である。ゆえに \(\measuredangle(T'B,T'J)=\measuredangle(T'J,T'C)\) となり，直線 \(T'J\)（これは直線 \(T'D\) である）は \(\angle BT'C\) の二等分線のいずれかである。

段階 4：\(\Gamma'\) は \(T'\) で \(\omega\) に接する. \(D\) は線分 \(BC\) の内部にあるから \(\Gamma'\) の内部にある。したがって直線 \(T'D\) は \(\Gamma'\) と \(T'\) 以外の点 \(W\) で交わり，\(D\) は \(T'\) と \(W\) の間にある。段階 3 より \(T'W\) は \(\angle BT'C\) の内角または外角の二等分線であるから，\(W\) は \(\Gamma'\) の弧 \(BC\) の一方の中点であり，\(W\) における \(\Gamma'\) の接線は \(BC\) に平行である。\(T'\) を中心とし \(D\) を \(W\) に移す相似変換 \(h\)（相似比 \(T'W/T'D\) は正）を考える。\(h\) は \(\omega\) を，\(T'\) を通り，\(BC\) の像すなわち \(W\) を通り \(BC\) に平行な直線に \(W\) で接する円に移す。\(\Gamma'\) も同じ二つの性質をもつ。一点 \(T'\) を通り，与えられた直線に与えられた点 \(W\) で接する円はただ一つである（中心は \(W\) における垂線と線分 \(T'W\) の垂直二等分線の交点であり，\(T'\) は接線上にないからこの二直線はただ一点で交わる）。よって \(h(\omega)=\Gamma'\) である。両方の円上にある点を中心として相似な二円はその点で接するから，\(\Gamma'\) は \(T'\) で \(\omega\) に接する。

段階 5：\(B,C\) を通り \(\omega\) に接する円はただ一つである. そのような円を \(\Sigma\)，中心を \(O\)，半径を \(R\) とする。\(D\) は弦 \(BC\) の内点であるから \(\Sigma\) の内部にあり，したがって \(\Sigma\) は \(\omega\) に外接し得ない（外接する二円の円板は \(\Sigma\) 上の一点でしか交わらない）。また \(B\) は \(\omega\) の外部にあるから \(\Sigma\) は \(\omega\) の内部にない。よって \(\omega\) は \(\Sigma\) に内接し，\(OI=R-r\) である。\(BC\) の中点を原点，\(BC\) を \(x\) 軸にとり，\(BC=a\)，\(I=(u,r)\)（\(u\) は \(D\) の \(x\) 座標で \(|u|<a/2\)），\(O=(0,k)\) とおくと \(R^2=a^2/4+k^2\) である。\(u^2+(k-r)^2=(R-r)^2\) を展開すると \(R-k=(a^2/4-u^2)/(2r)=:q>0\) を得て，さらに \(R+k=(R^2-k^2)/q=a^2/(4q)\) となる。ゆえに \(k\) と \(R\) は一意に定まり，\(\Sigma\) はただ一つである。

結論. 段階 4, 5 より \(\Gamma=\Gamma'\)，\(T=T'\) である。段階 2 より \(B,F,T,J\) は同一円周上にある。副産物として，\(T\) は円 \(CEJ\) 上および直線 \(DJ\) 上にもある。\(T,D,J\) が一直線上にあることは既知の補題（ISL 2002 G7 の核心）であり，上の議論はそれも証明している。

検算. 鋭角および鈍角の無作為な三角形 196,183 個について，接する条件から \(\Gamma\) を厳密に計算して \(T\) を求め，円 \(BFJ\) と \(CEJ\) を調べた。\(T\) のこれらの円からの相対的なずれは最大 \(1.1\times10^{-{12}}\) であり，\(T,D,J\) の共線性は \(3\times10^{-{10}}\) 以内で成り立った。

答え. 証明完了：接点 \(T\) は円 \(BFJ\) 上にある（対称的に円 \(CEJ\) 上にもある）。\(T\) は直線 \(DJ\) と内接円のもう一つの交点である。
