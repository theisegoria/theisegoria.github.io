数学オリンピックの問題

辺 BC の中点を通る弦

三角形 \(ABC\)（\(AB\neq AC\)）の外接円を \(\Omega\) とし，内接円が辺 \(BC,CA,AB\) と接する点をそれぞれ \(D,E,F\)，頂点 \(A\) に対する傍心を \(J\) とする。\(D\) から直線 \(EF\) に下ろした垂線の足を \(K\) とし，直線 \(AK\) と \(\Omega\) の \(A\) 以外の交点を \(Z\) とする。辺 \(BC\) の中点を \(M\) とし，直線 \(ZM\) と \(\Omega\) の \(Z\) 以外の交点を \(W\) とする。このとき \(\angle AWJ=90^\circ\) であることを証明せよ。

解答を開く

記号. 辺の長さを \(a,b,c\)，半周長を \(s\) とし，\(p=BD=BF=s-b\)，\(q=CD=CE=s-c\) とおく。\(AB\neq AC\) より \(p\neq q\) である。\(A\) に対する傍接円が直線 \(AB,AC\) に接する点をそれぞれ \(F',E'\) とすると，\(BF'=s-c=q\)，\(CE'=s-b=p\) であり，\(F'\) は半直線 \(AB\) 上で \(B\) の先に，\(E'\) は半直線 \(AC\) 上で \(C\) の先にある。

\(W\) での角の追跡が行き詰まる理由. \(Z\) と \(W\) は \(K\) や \(M\) を通る直線で定められており，どちらの定義からも \(W\) における使える角は得られない。用いるべき量は，\(\Omega\) 上の点 \(X\) に対する比 \(XB/XC\) である。各開弧 \(BC\) の上でこの比は \(0\) から \(\infty\) まで連続かつ狭義単調に変化するので，\(\Omega\) 上の点はこの比とそれが属する弧によって決まる。以下ではこの比を \(K\) から \(Z\)，さらに \(W\) へと追跡し，最後に得られる値を傍接円の中に見いだす。

段階 1：\(FK/KE=p/q\). 接線と弦のなす角により \(\angle DFE=\angle EDC=90^\circ-\tfrac{C}{2}\)，\(\angle DEF=\angle FDB=90^\circ-\tfrac{B}{2}\) であり，いずれも鋭角であるから \(K\) は線分 \(EF\) の内部にある。二等辺三角形 \(BDF,\ CDE\) より \(DF=2p\sin\tfrac{B}{2}\)，\(DE=2q\sin\tfrac{C}{2}\) である。直角三角形 \(DKF,\ DKE\) において

\[FK=DF\cos\angle DFE=2p\sin\tfrac{B}{2}\sin\tfrac{C}{2},\qquad KE=DE\cos\angle DEF=2q\sin\tfrac{C}{2}\sin\tfrac{B}{2}\]

となり，\(FK/KE=p/q\) を得る。

段階 2：\(ZB/ZC=p/q\) であり，\(Z\) は \(A\) を含まない弧 \(BC\) 上にある. \(K\) は線分 \(EF\) の内点であるから三角形の内部にあり，半直線 \(AK\) は線分 \(BC\) の内部を通過したのち，\(A\) を含まない弧 \(BC\) 上で \(\Omega\) と交わる。これが \(Z\) である。\(\beta=\angle BAZ\)，\(\gamma=\angle ZAC\) とおく。\(A\) からの高さが共通な三角形 \(AFK,\ AKE\) の面積を比べ，\(AF=AE\) を用いると

\[\frac{FK}{KE}=\frac{[AFK]}{[AKE]}=\frac{\tfrac12\,AF\cdot AK\sin\beta}{\tfrac12\,AE\cdot AK\sin\gamma}=\frac{\sin\beta}{\sin\gamma}\]

である。\(\Omega\) の半径を \(R\) とすると正弦定理より \(ZB=2R\sin\beta\)，\(ZC=2R\sin\gamma\) である。段階 1 と合わせて \(ZB/ZC=p/q\) を得る。

段階 3：\(M\) を通る弦は比を逆数にする. 弦 \(BC\) と \(ZW\) は \(\Omega\) の内部の点 \(M\) で交わるので \(MB\cdot MC=MZ\cdot MW\) である。よって \(MZ/MC=MB/MW\) であり，\(M\) における対頂角と合わせて三角形 \(MZB\) と \(MCW\) は相似となり，\(ZB/CW=MZ/MC\) を得る。同様に三角形 \(MZC\) と \(MBW\) は相似で，\(ZC/BW=MZ/MB\) を得る。\(MB=MC\) より右辺は等しいから \(ZB\cdot BW=ZC\cdot CW\)，すなわち

\[\frac{WB}{WC}=\frac{ZC}{ZB}=\frac{q}{p}=\frac{BF'}{CE'}\]

である。さらに \(Z\) は直線 \(BC\) に関して \(A\) と反対側にあり，\(M\) は \(BC\) 上で \(Z\) と \(W\) の間にあるから，\(W\) は弧 \(BAC\) 上にある。また \(W\neq A\) である。実際 \(W=A\) ならば \(c/b=(s-c)/(s-b)\) となり，これは \(s(c-b)=0\) に帰着する。

段階 4：\(W\) は \(A,F',E'\) を通る円の上にある. \(W\) と \(A\) はともに弧 \(BAC\) 上にあるから，弧 \(BAC\) の内側で両者を結ぶ \(\Omega\) の弧は \(B\) も \(C\) も含まない。したがって \(B\) と \(C\) は直線 \(WA\) に関して同じ側にあり，円周角により \(\angle WBA=\angle WCA\) である。\(F'\) は半直線 \(AB\) 上で \(B\) の先に，\(E'\) は半直線 \(AC\) 上で \(C\) の先にあるから

\[\angle WBF'=180^\circ-\angle WBA=180^\circ-\angle WCA=\angle WCE'\]

である。段階 3 の \(WB/BF'=WC/CE'\) と合わせて，二辺比夾角相等により三角形 \(WBF'\) と \(WCE'\) は相似である。ゆえに \(\angle WF'A=\angle WF'B=\angle WE'C=\angle WE'A\) を得る。\(F'\) と \(E'\) は直線 \(WA\) に関して \(B,C\) と同じ側にあるので，この等しい角から \(A,W,F',E'\) は同一円周上にある。

段階 5：結論. \(JF'\perp AB\)，\(JE'\perp AC\) であるから，\(A,F',E'\) を通る円は \(AJ\) を直径とする円である。段階 4 より \(W\) はこの円の上にある。最後に \(W\neq J\) である。実際 \(J\) は半直線 \(AI\) 上で弧 \(BC\) の中点（これは線分 \(IJ\) の中点である）より先にあり \(\Omega\) の外部にあるが，\(W\) は \(\Omega\) 上にある。よってタレスの定理により \(\angle AWJ=90^\circ\) である。

注意. 同じ議論から，\(W\) は弧 \(BAC\) 上の点で \(\angle BWC\) の二等分線が傍接円と \(BC\) の接点を通るものであり，\(Z\) は反対側の弧上の点で \(\angle BZC\) の二等分線が \(D\) を通るものであることが分かる。

検証. 無作為に生成した 270,067 個の三角形（鋭角・鈍角を含み \(AB\neq AC\)）で数値的に確かめた。\(\angle AWJ\) の余弦は \(3.3\times10^{-12}\) を超えず，比 \(ZB/ZC=(s-b)/(s-c)\)，\(WB/WC=(s-c)/(s-b)\) も相対誤差 \(4\times10^{-11}\) 未満で成り立った。

答え. 証明終わり：\(\angle AWJ=90^\circ\)。\(W\) は \(\Omega\) と \(AJ\) を直径とする円の \(A\) 以外の交点である。
