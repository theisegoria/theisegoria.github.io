数学オリンピックの問題

重み付き 3 次方程式の有界な解

恒等的には 0 でない有界な 2 回微分可能関数 \(y:\mathbb{R}\to\mathbb{R}\) であって，すべての実数 \(x\) に対して

\[(1+x^2)^3\,y''(x)+c\,y(x)^3=0\]

を満たすものが存在するような実数 \(c\) をすべて求めよ。

解答を開く

答は \(c\ge 0\) である。

直接の攻め方が行き詰まる理由。 変数 \(x\) のままでは，重み \((1+x^2)^{-3}\) が \(x\) に依存するため保存量がなく，拡大 \(x\mapsto\lambda x\) や反転 \(x\mapsto 1/x\) に対する不変性もない。\(c<0\) の場合は凸性で論じることもできるが，\(c>0\) の場合は \(-\infty\) と \(+\infty\) の両側で有界にとどまる解を作らねばならず，これは 1 点での初期値を選ぶだけでは課せない両端条件である。重みを完全に消す変数変換が鍵となる。

第1段：変数変換。 \(x=\tan\theta\)（\(\theta\in(-\pi/2,\pi/2)\)），\(y(x)=u(\theta)/\cos\theta\)，すなわち \(u(\theta)=y(\tan\theta)\cos\theta\) とおく。\(u\) が 2 回微分可能であることと \(y\) がそうであることは同値である。\(d\theta/dx=\cos^2\theta\) より

\[\frac{dy}{dx}=\cos^2\theta\,\frac{d}{d\theta}\Big(\frac{u}{\cos\theta}\Big)=u'\cos\theta+u\sin\theta,\qquad \frac{d^2y}{dx^2}=\cos^3\theta\,(u''+u)\]

を得る。\((1+x^2)^3=\sec^6\theta\)，\(y^3=\sec^3\theta\,u^3\) であるから，方程式は \(\sec^3\theta\,(u''+u+cu^3)=0\)，すなわち

\[u''+u+c\,u^3=0\quad(-\pi/2<\theta<\pi/2)\tag{*}\]

となる。重みの 3 乗と \(y^3\) がちょうど釣り合うことが本質である。

第2段：有界性を境界条件に言い換える。 \(|y|\le M\) ならば \(|u(\theta)|\le M\cos\theta\) であり，\(u\) は \(\pm\pi/2\) で 0 に近づく。さらに \(u\) が有界なので \(u''=-u-cu^3\) も有界であり，\(u'\) は有界かつ一様連続である。よって \(u\) は \([-\pi/2,\pi/2]\) 上の \(C^1\) 級関数に拡張され，\(u(\pm\pi/2)=0\) を満たす。逆に，\(u\) が \([-\pi/2,\pi/2]\) を含む開区間で \((*)\) を満たし \(u(\pm\pi/2)=0\) であるとし，そこでの \(|u'|\) の最大値を \(L\) とする。平均値の定理より \(|u(\theta)|\le L(\pi/2-|\theta|)\) であり，\(\cos\theta=\sin(\pi/2-|\theta|)\ge\frac{2}{\pi}(\pi/2-|\theta|)\) であるから \(|y|=|u|/\cos\theta\le L\pi/2\) となり，\(y\) は有界である。

第3段：\(c<0\) では解が存在しない。 \(c=-d\)（\(d>0\)）とおき，0 でない有界な解 \(y\) があったとする。このとき \(|u|\le M\cos\theta\) であり \(u'\) は有界である。\((*)\) に \(u\) を掛けて \([-\pi/2+\varepsilon,\pi/2-\varepsilon]\) で積分すると，境界項 \(uu'\) は 0 に近づくので

\[\int_{-\pi/2}^{\pi/2}u'^2\,d\theta=\int_{-\pi/2}^{\pi/2}u^2\,d\theta-d\int_{-\pi/2}^{\pi/2}u^4\,d\theta\]

を得る。一方，平方を展開し \(2uu'\tan\theta\) を部分積分すると

\[\int_{-\pi/2}^{\pi/2}\big(u'+u\tan\theta\big)^2\,d\theta=\int_{-\pi/2}^{\pi/2}u'^2\,d\theta-\int_{-\pi/2}^{\pi/2}u^2\,d\theta\]

となる。ここで境界項 \(u^2\tan\theta\) は \(|u^2\tan\theta|\le M^2\cos\theta\,|\sin\theta|\to0\) より消える（これは長さ \(\pi\) の区間でのウィルティンガーの不等式である）。よって \(\int u'^2\ge\int u^2\) であり，前の等式と比べて \(d\int u^4\le0\) を得る。ゆえに \(u\equiv0\)，\(y\equiv0\) となり矛盾である。（別証：\(c<0\) では \(yy''\ge0\) であるから，\(y\) は正の部分で凸となり，\(\mathbb{R}\) 全体で有界なこのような関数は 0 しかない。）

第4段：\(c=0\)。 定数関数 \(y\equiv1\) が条件を満たす。

第5段：\(c>0\) での解の構成。 \((*)\) の解で \(u(0)=0\)，\(u'(0)=a>0\) を満たすものを \(u\) とする。エネルギー \(u'^2+u^2+\frac c2u^4=a^2\) が保存されるので，\(u\) は有界で \(\mathbb{R}\) 全体で存在する。解の一意性より \(-u(-\theta)\) も同じ解であるから，\(u\) は奇関数である。\(m>0\) を \(m^2+\frac c2m^4=a^2\) により定める。\(u'\) が 0 になりうるのは \(u=\pm m\) のときに限るので，\(u\) は 0 から増加し，最初に最大値 \(m\) に達する時刻は

\[\tau=\int_0^m\frac{dv}{\sqrt{a^2-v^2-\frac c2v^4}}=\int_0^1\frac{ds}{\sqrt{(1-s^2)\,\big(1+k(1+s^2)\big)}},\qquad k=\frac{cm^2}{2}\]

である。ここで因数分解 \(a^2-v^2-\frac c2v^4=(m^2-v^2)\big(1+\frac c2(m^2+v^2)\big)\) と \(v=ms\) を用いた。\(a\) が \((0,\infty)\) を動くとき \(k\) も \((0,\infty)\) を動く。被積分関数は \(1/\sqrt{1-s^2}\) で押さえられるので，\(\tau(k)\) は連続かつ狭義単調減少であり，\(k\to0\) で \(\pi/2\) に近づき，\(\tau(k)\le\frac{\pi}{2\sqrt{1+k}}\to0\)（\(k\to\infty\)）を満たす。よって \(\tau=\pi/4\) となる \(k\) がとれる。\(\theta=\pi/4\) で \(u=m\)，\(u'=0\) であり，\((*)\) は自励的な 2 階方程式であるから \(u(\pi/2-t)=u(t)\) がすべての \(t\) で成り立つ。ゆえに \(u(\pi/2)=u(0)=0\) であり，奇関数性から \(u(-\pi/2)=0\) である。第2段より

\[y(x)=\sqrt{1+x^2}\;u(\arctan x)\]

は 0 でない有界な解である（奇関数であり，0 になるのは \(x=0\) のみで，\(x\to\pm\infty\) で \(\pm a\) に収束する）。なお \(c=1\) の場合を示せば十分である。\(y\) が \(c=1\) の方程式の解ならば，\(y/\sqrt c\) は一般の \(c>0\) に対する解となるからである。

結論。 0 でない有界な解が存在するのは \(c\ge0\) のときであり，そのときに限る。

検算。 \(c=1\) に対し数値的に根を求めると \(k\approx2.0662\)，振幅 \(m\approx2.0328\)，\(a\approx3.5596\) となり，\((*)\) をルンゲ・クッタ法で積分すると \(u(\pi/2)\approx3\times10^{-14}\) を得る。元の方程式を \(x\) について \(y(0)=0\)，\(y'(0)=a\) から \(x=10^4\) まで直接積分すると \(y\) は有界にとどまり（\(3.5596\) に落ち着き，傾きは \(6\times10^{-12}\)），\(x=3\) で \(\sqrt{1+x^2}\,u(\arctan x)\) と \(10^{-11}\) の精度で一致する。\(a\) を \(1\%\) 変えると線形に増大し，\(c=-1\) では無作為な初期値の解はすべて線形に増大した。

答え. \(c\ge 0\)（\(c=0\) では定数関数，\(c>0\) では奇関数解 \(\sqrt{1+x^2}\,u(\arctan x)\) が存在し，\(c<0\) では存在しない）
