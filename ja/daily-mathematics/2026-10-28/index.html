数学オリンピックの問題

対ごとの和と積が一致する実数

相異なる \(n\) 個の実数 \(x_1,\dots,x_n\) であって，\(\binom{n}{2}\) 個の和 \(x_i+x_j\) と \(\binom{n}{2}\) 個の積 \(x_ix_j\) \((i<j)\) が並べ方を除いて一致するもの，すなわち多重集合として

\[\{x_i+x_j\}_{i<j}=\{x_ix_j\}_{i<j}\]

をみたすものが存在するような \(2\) 以上の整数 \(n\) をすべて求めよ。

解答を開く

答. \(2\) 以上のすべての整数 \(n\) である。

最初の直感が誤る理由. 大きな数の積は \(2\) 次的に，和は \(1\) 次的に増えるので，\(n\) が大きいと不可能だと示したくなる。しかしこの方針は完結しない。実際にはすべての \(n\) で条件をみたす数が存在するからである。なお \(n\ge 3\) のときすべてを正にはできない。\(0<x_1<x_2<\dots<x_n\) とすると，最小の和と最小の積はそれぞれ \(x_1+x_2\) と \(x_1x_2\)，\(2\) 番目に小さいものは \(x_1+x_3\) と \(x_1x_3\) であるから，\(x_1=\tfrac{x_2}{x_2-1}=\tfrac{x_3}{x_3-1}\) となり \(x_2=x_3\) が従う。したがって構成には符号の混在が必要であり，\(\binom{n}{2}!\) 通りの対応を闇雲に調べても手がかりは得られない。

\(n=2\) の場合. \(x\ne y\) かつ \(x+y=xy\) となればよく，たとえば \(x=3\)，\(y=\tfrac32\) である。この場合は以下の一般的な構成にも含まれる。

構成. \(m=2n+1\) とおき，整数 \(r\) に対して \(c(r)=2\cos\tfrac{2\pi r}{m}\) と定める。\(k=1,\dots,n\) に対して \(x_k=c(k)\) とおく。\(\tfrac{2\pi k}{m}\) は区間 \((0,\pi)\) にあり，そこで余弦は狭義単調減少であるから，これらは相異なる。\(c(r)\) は \(r\) の \(m\) を法とする剰余のみで決まり，\(c(-r)=c(r)\) をみたす。\(\mathbb{Z}_m\) の部分集合 \(\{r,-r\}\) を類 \([r]\) とよぶ。\(m\) は奇数なので \(0\) でない類はちょうど \([1],\dots,[n]\) であり，\(c\) は類 \([k]\) 上で一定値 \(x_k\) をとる。

積が和に変わる. 積和公式 \(2\cos\alpha\cdot 2\cos\beta=2\cos(\alpha+\beta)+2\cos(\alpha-\beta)\) により

\[x_ax_b=c(a+b)+c(a-b)\]

を得る。すなわち \(\{[a],[b]\}\) で添字づけられた対の積は，\(\{[a+b],[a-b]\}\) で添字づけられた対の和に等しい。あとはこの添字の付け替えが対の置換になっていることを示せばよい。

類の対の上の全単射. \(0\) でない相異なる \(2\) つの類からなる非順序対の全体を \(\Pi\) とする。\(\Pi\) は \(\binom{n}{2}\) 個の元をもち，対 \(i<j\) を添字づける。\(\varphi(\{[a],[b]\})=\{[a+b],[a-b]\}\) と定める。

(i) \(\varphi\) は矛盾なく定義される。\(b\) を \(-b\) に替えると \(2\) つの成分が入れ替わるだけであり，\(a\) を \(-a\) に替えると \([-(a-b)]=[a-b]\)，\([-(a+b)]=[a+b]\) となり，\(a\) と \(b\) を入れ替えると \([b+a]\) と \([b-a]=[a-b]\) となる。

(ii) 値は \(\Pi\) に属する。\([a]\ne[b]\) は \(a\not\equiv\pm b\) を意味するので，\(a+b\) と \(a-b\) は \(m\) を法として \(0\) でない。もし \([a+b]=[a-b]\) ならば \(a+b\equiv a-b\) または \(a+b\equiv b-a\)，すなわち \(2b\equiv 0\) または \(2a\equiv 0\) である。\(m\) は奇数なので \(2\) は \(m\) を法として可逆であり，\(a\equiv 0\) または \(b\equiv 0\) となって仮定に反する。

(iii) \(\varphi\) は単射である。\(h=n+1\) は \(m\) を法とする \(2\) の逆元である。\(\psi(\{[u],[v]\})=\{[h(u+v)],[h(u-v)]\}\) は同様の確認により矛盾なく定義されて \(\Pi\) に値をとり，\(\psi(\varphi(\{[a],[b]\}))=\{[a],[b]\}\) が成り立つ。有限集合 \(\Pi\) からそれ自身への単射は全単射である。

結論. \(\{[a],[b]\}\) が \(\Pi\) を動くとき，積 \(x_ax_b\) は \(\{[u],[v]\}=\varphi(\{[a],[b]\})\) に対する値 \(c(u)+c(v)\) を動く。\(\varphi\) は \(\Pi\) の全単射なので，これらはちょうどすべての対の和をちょうど一度ずつ尽くす。よってすべての \(n\ge 2\) について，積の多重集合と和の多重集合は一致する。

例. \(n=3\) のとき数は \(2\cos\tfrac{2\pi}{7}\)，\(2\cos\tfrac{4\pi}{7}\)，\(2\cos\tfrac{6\pi}{7}\) であり，\(t^3+t^2-2t-1\) の根である。\(c(4)=c(3)\)，\(c(5)=c(2)\) を用いると \(x_1x_2=x_3+x_1\)，\(x_1x_3=x_3+x_2\)，\(x_2x_3=x_2+x_1\) を得る。手計算で構成を見つける道筋もこれである。\(n=3\) を解くと正七角形の \(3\) 次式が現れ，\(n=4\) を解くと \(2\cos\tfrac{2\pi k}{9}\) が現れる。

検証. \(n=2\) から \(60\) までのすべての \(n\) について，和と積を整列した列が \(3\cdot 10^{-15}\) 以内で一致することを数値的に確認し，さらに \(n\le 200\) のすべての \(n\) について \(\varphi\) が \(\Pi\) の全単射であることを厳密な計算で確認した。

答え. \(2\) 以上のすべての整数 \(n\)（たとえば \(x_k=2\cos\tfrac{2\pi k}{2n+1}\)，\(k=1,\dots,n\)）
