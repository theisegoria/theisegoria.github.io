2026年10月15日の解答

この日のカードは難しい定積分とオリジナルのパトナム型の問題の2枚である。まず自分で考え、詰まったら解答を開くこと。

積分

区間 [-1, 1] 上の二つの対数の積の積分

次の定積分を閉じた形で求めよ。

\[\int_{-1}^{1}\ln\Bigl(1+\sqrt{\tfrac{2}{1-x}}\Bigr)\ln\Bigl(1+\sqrt{\tfrac{2}{1+x}}\Bigr)\,dx\]
解答を開く

この積分を \(I\) とおく。\(I=2\pi-4\ln2-\tfrac{\pi^2}{6}\approx1.8656625\) であることを示す。

素直な方法が行き詰まる理由。 \(x=\cos2\theta\) とおくと \(I=2\int_0^{\pi/2}\ln(1+\csc\theta)\ln(1+\sec\theta)\sin2\theta\,d\theta\) となる。初等的に見えるが，二つの対数が \(\sin\theta\) と \(\cos\theta\) を結びつけており，どちらかを級数展開すると扱いにくい引数の二重対数が現れて，うまくまとまらない。各因子を母関数の積分とみなし，積を直交性で処理するのが要点である。

第1段：各因子は母関数の積分である。 \(-1<x<1\) に対して \(G(x)=\int_0^1\frac{dt}{\sqrt{1-2xt+t^2}}\) とおく。\(\ln\bigl(t-x+\sqrt{1-2xt+t^2}\bigr)\) が原始関数であるから \(G(x)=\ln\bigl(1-x+\sqrt{2-2x}\bigr)-\ln(1-x)\) である。\(u=\sqrt{(1-x)/2}\) とおいて \(1-x=2u^2\) と書けば \(G(x)=\ln\frac{2u^2+2u}{2u^2}=\ln\bigl(1+\tfrac1u\bigr)=\ln\Bigl(1+\sqrt{\tfrac{2}{1-x}}\Bigr)\) を得る。よって被積分関数はちょうど \(G(x)\,G(-x)\) である。

第2段：ルジャンドル展開。 ルジャンドル多項式の母関数は \(|x|\le1\)，\(|t|<1\) で \(\frac{1}{\sqrt{1-2xt+t^2}}=\sum_{n\ge0}P_n(x)t^n\) である。\(0\le t\le r<1\) で積分して \(r\to1\) とすれば，\(-1<x<1\) で \(G(x)=\sum_{n\ge0}\frac{P_n(x)}{n+1}\) を得る（アーベルの定理による。内部の \(x\) を固定すれば \(P_n(x)=O(n^{-1/2})\) であるから級数は収束する）。また \(\int_{-1}^1P_n^2=\frac{2}{2n+1}\) かつ \(\sum_n\frac{1}{(n+1)^2}\cdot\frac{2}{2n+1}<\infty\) であるから，この級数は \(L^2[-1,1]\) でも収束し，その極限はほとんど至る所で各点極限と一致する。\(P_n(-x)=(-1)^nP_n(x)\) より \(G(-x)=\sum_{n\ge0}\frac{(-1)^nP_n(x)}{n+1}\) であり，直交関係 \(\int_{-1}^1P_mP_n=\frac{2\delta_{mn}}{2n+1}\) によって二つの級数の内積は \[I=\sum_{n\ge0}\frac{(-1)^n}{(n+1)^2}\cdot\frac{2}{2n+1}\] となる。

第3段：部分分数分解。 \(\frac{1}{(2n+1)(n+1)^2}=\frac{4}{2n+1}-\frac{2}{n+1}-\frac{1}{(n+1)^2}\) が成り立つ（\(n=0\) で \(4-2-1=1\)）。三つの交代級数はそれぞれ収束し，\(\sum_{n\ge0}\frac{(-1)^n}{2n+1}=\frac{\pi}{4}\)（ライプニッツの級数），\(\sum_{n\ge0}\frac{(-1)^n}{n+1}=\ln2\)，\(\sum_{n\ge0}\frac{(-1)^n}{(n+1)^2}=\frac{\pi^2}{12}\) である。したがって \[I=2\Bigl(\pi-2\ln2-\frac{\pi^2}{12}\Bigr)=2\pi-4\ln2-\frac{\pi^2}{6}\] を得る。

関連する積分。 符号のない同じ議論により \(\int_{-1}^1G(x)^2\,dx=2\sum_{n\ge0}\frac{1}{(2n+1)(n+1)^2}=8\ln2-\frac{\pi^2}{3}\) も得られる。

数値検証。 \(x=\cos2\theta\) と置換し，対称性により \([0,\pi/4]\) に折り返したうえで，対数的な端点を緩和するため \(\theta=\tfrac{\pi}{4}w^3\) とおいて，100 点の複合ガウス–ルジャンドル求積（40 区間と 200 区間）で \(I\) を計算した。どちらも \(2\pi-4\ln2-\pi^2/6=1.8656625180915\ldots\) と約 \(10^{-15}\) の精度で一致した。関連する積分の値も同様に確かめた。

答え. \(2\pi-4\ln2-\dfrac{\pi^2}{6}\approx1.8656625\)

競技数学の問題

既約な二次式で消える最も疎な実行列

\(b,\,c\) を \(b^2<4c\) をみたす実数とする。実数を成分とする \(2026\times2026\) 行列 \(A\) が次の等式をみたすとき，\(A\) の \(0\) でない成分の個数の最小値を \(b,\,c\) を用いて求めよ。

\[A^2+bA+cI=0\]
解答を開く

\(n=2026\)，\(p(x)=x^2+bx+c\) とおく。最小値は \(b=0\) のとき \(2026\)，\(b\neq0\) のとき \(3039=\tfrac32\cdot2026\) であり，\(c\) にはよらないことを示す。\(b^2<4c\) より \(p\) は実根をもたず，また \(c>b^2/4\ge0\) である。

最初の発想だけでは足りない理由。 最も疎な正則行列は単項行列（各行各列に 0 でない成分がちょうど 1 個）である。\(A\) が単項行列なら \(A^2\) も単項行列であるが，\(-bA-cI\) は対角成分と \(A\) の非対角成分の位置の両方に 0 でない成分をもつ。\(b\neq0\) のとき両者が一致するのは \(A\) が対角行列の場合に限られ，そのとき \(A\) は実固有値をもってしまう。よって \(b\neq0\) では \(n\) 個より多くの成分が必要であり，問題はそれが何個かである。

第1段：どの行も 0 でない。 \(c\neq0\) かつ \(A(A+bI)=-cI\) であるから \(A\) は正則である。したがって各行は 0 でない成分を少なくとも 1 個もち，\(A\) の 0 でない成分は少なくとも \(n\) 個である。

第2段：\(b=0\) の場合。 ブロック \(B=\begin{pmatrix}0&-c\\1&0\end{pmatrix}\) は \(B^2=-cI\) をみたす。\(B\) を \(1013\) 個並べたブロック対角行列は \(A^2+cI=0\) をみたし，0 でない成分はちょうど \(2026\) 個である。よって最小値は \(2026\) である。

第3段：孤立した行は相手の行を決める（\(b\neq0\)）。 0 でない成分がちょうど 1 個の行を孤立行とよぶ。行 \(i\) が孤立行で，その成分が第 \(j\) 列の \(a\) であるとすると \(e_i^{T}A=a\,e_j^{T}\) である。\(j=i\) ならば \(e_i^{T}p(A)=p(a)\,e_i^{T}\neq0\) となり矛盾するから，\(j\neq i\) である。\(A^2\) の第 \(i\) 行は \(e_i^{T}A\cdot A=a\cdot(A\text{ の第 }j\text{ 行})\) であり，\(-bA-cI\) の第 \(i\) 行は \(-ab\,e_j^{T}-c\,e_i^{T}\) である。ゆえに \[A\text{ の第 }j\text{ 行}=-b\,e_j^{T}-\tfrac{c}{a}\,e_i^{T}\] であり，\(b\neq0\)，\(c\neq0\) よりこの行の 0 でない成分はちょうど 2 個である。\(j\) を \(i\) の相手とよぶ。

第4段：数え上げ。 相手を対応させる写像は単射である。実際，異なる孤立行 \(i,i'\) が同じ相手 \(j\) をもてば，第 \(j\) 行は第 \(i\)，\(i'\)，\(j\) 列という相異なる 3 列に 0 でない成分をもち，第3段に反する。相手の行は成分をちょうど 2 個もつので孤立行ではない。孤立行の個数を \(L\)，成分がちょうど 2 個の行の個数を \(T\)，残りの行の個数を \(R\) とすると，\(L+T+R=n\) かつ \(L\le T\) である。0 でない成分の個数は少なくとも \[L+2T+3R\ \ge\ \tfrac32(L+T)+\tfrac32R=\tfrac32n\] であり，最初の不等号で \(T\ge L\) を用いた。よって少なくとも \(3039\) 個が必要である。

第5段：等号の実現。 コンパニオン行列 \(C=\begin{pmatrix}0&-c\\1&-b\end{pmatrix}\) の固有多項式は \(x^2+bx+c\) であるから，ケイリー–ハミルトンの定理により \(p(C)=0\) であり，0 でない成分はちょうど 3 個である。\(C\) を \(1013\) 個並べたブロック対角行列は \(A^2+bA+cI=0\) をみたし，0 でない成分は \(3\cdot1013=3039\) 個である。

検証。 上の議論は \(p\) がその体で根をもたないことしか使わないので，有限体上で全数探索により確かめた。\(\mathbb{F}_2\) 上で \(p=x^2+x+1\) とすると，4 次の行列 \(2^{16}\) 個すべてを調べて最小値は \(6\)（2 次では \(3\)）であった。\(\mathbb{F}_5\) 上の \(x^2+x+1\) では 2 次で最小値 \(3\)，\(b=0\) に対応する \(\mathbb{F}_5\) 上の \(x^2+2\) と \(\mathbb{F}_3\) 上の \(x^2+1\) では最小値 \(2\) であった。実数のブロック構成も，いくつかの \((b,c)\) について 2026 次で残差がちょうど \(0\) となることを確かめた。

答え. \(b=0\) のとき \(2026\)，\(b\neq0\) のとき \(3039\)（\(c\) によらない）
